# Thylacine

The company page for Thylacine, a studio that makes software products and takes custom work. Live at https://thylacinehq.github.io/thylacine/.

## What it is

A single static page. As you scroll, a row of stripes gathers into a thylacine that walks and opens its jaws. The page lists what the studio builds, says no projects are listed yet, and gives a contact email. With reduced motion or no JavaScript it falls back to a plain stacked page with a static drawing.

## Status

Live on GitHub Pages. There are no tests and no build step.

## Stack

HTML, CSS and vanilla JavaScript. No libraries and no dependencies. The animal is generated by `thylacine.js`, which the page and `tools/thylacine.mjs` both use. Fonts are Instrument Sans and Instrument Serif, served from `fonts/`.

## Run it

Open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000.

To regenerate the static fallback drawing inside `index.html`, or to preview poses as an SVG (needs Node):

```bash
node tools/thylacine.mjs fallback
node tools/thylacine.mjs preview out.svg
```

`DESIGN.md` has the design notes: the mark, the colour tokens, and how the animal is built from bars. `tools/og.html` is the source for `og.png`.
